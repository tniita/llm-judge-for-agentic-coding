注文のキャンセル機能を追加する。

- `OrderService.cancel_order(user: User, order_id: int) -> Order` を追加する

R1: キャンセルすると注文の全商品の在庫を戻し、注文の status を CANCELLED にして返す
R2: キャンセルできるのは注文した本人か admin ロールのユーザーだけ。それ以外は PermissionError を送出する
R3: 存在しない注文 ID なら LookupError（KeyError を含む）を送出する
R4: status が SHIPPED の注文は ValueError を送出してキャンセルしない
R5: すでに CANCELLED の注文を再度キャンセルしようとしたら ValueError を送出し、在庫を二重に戻さない
完了条件: 既存テストと追加したテストがすべて通ること
