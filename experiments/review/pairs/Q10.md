## タスク

商品カテゴリごとの消費税計算を追加する。

- 新規モジュール `shoplib/tax.py`
- `TaxBreakdown`（dataclass）: `subtotal: Decimal`, `tax: Decimal`, `total: Decimal`
- `calculate_tax(items: list[CartItem], rates: dict[str, Decimal], default_rate: Decimal = Decimal("0.10")) -> TaxBreakdown`

R1: 税額は明細（CartItem）ごとに「明細の小計 × 税率」を計算し、1 円未満を切り捨て（ROUND_DOWN）てから合計する
R2: 税率は商品の category をキーに rates から引く。無ければ default_rate を使う
R3: total は subtotal + tax
R4: rates の値または default_rate が 0 未満または 1 より大きければ ValueError を送出する
R5: items が空なら subtotal・tax・total はすべて 0
完了条件: 既存テストと追加したテストがすべて通ること

+class TaxBreakdown:
+    subtotal: Decimal
+    tax: Decimal
+    total: Decimal
+
+
+def _validate_rate(rate: Decimal) -> None:
+    if rate < 0 or rate > 1:
+        raise ValueError(f"tax rate must be between 0 and 1: {rate}")
+
+
+def calculate_tax(
+    items: list[CartItem],
+    rates: dict[str, Decimal],
+    default_rate: Decimal = Decimal("0.10"),
+) -> TaxBreakdown:
+    """明細ごとに小計×税率を 1 円未満切り捨てで計算し、合計する。"""
+    _validate_rate(default_rate)
+    for rate in rates.values():
+        _validate_rate(rate)

+    tax = Decimal("0")

+        subtotal += line
+        tax += (line * rate).quantize(Decimal("1"), rounding=ROUND_DOWN)
+    return TaxBreakdown(subtotal=subtotal, tax=tax, total=subtotal + tax)

+from dataclasses import dataclass
+from decimal import ROUND_DOWN, Decimal
+
+from shoplib.models import CartItem
+
+_ZERO = Decimal("0")
+_ONE = Decimal("1")
+_YEN = Decimal("1")
+
+
+@dataclass(frozen=True)
+class TaxBreakdown:
+    subtotal: Decimal
+    tax: Decimal
+    total: Decimal
+
+
+def _validate_rate(rate: Decimal, name: str) -> None:
+    if not _ZERO <= rate <= _ONE:
+        raise ValueError(f"{name} must be between 0 and 1, got {rate}")
+
+
+def calculate_tax(
+    items: list[CartItem],
+    rates: dict[str, Decimal],
+    default_rate: Decimal = Decimal("0.10"),
+) -> TaxBreakdown:
+    """カテゴリ別の税率で消費税を計算する。
+
+    税額は明細ごとに「明細の小計 × 税率」を 1 円未満切り捨てしてから合計する。
+    税率は商品の category をキーに rates から引き、無ければ default_rate を使う。
+    税率（rates の全値と default_rate）が 0 未満または 1 より大きい場合は ValueError。
+    """
+    _validate_rate(default_rate, "default_rate")
+    for category, rate in rates.items():
+        _validate_rate(rate, f"rate for category {category!r}")
+
+    subtotal = _ZERO
+    tax = _ZERO
+    for item in items:
+        item_subtotal = item.subtotal
+        rate = rates.get(item.product.category, default_rate)
+        subtotal += item_subtotal
+        tax += (item_subtotal * rate).quantize(_YEN, rounding=ROUND_DOWN)
+
+    return TaxBreakdown(subtotal=subtotal, tax=tax, total=subtotal + tax)
