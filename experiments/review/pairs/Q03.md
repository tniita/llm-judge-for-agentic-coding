# Q03: どちらをマージすべきか

## タスク

shoplib/pricing.py にクーポン機能を追加する。

- `Coupon`（dataclass）: `code: str`, `kind: str`（"percent" または "fixed"）, `value: Decimal`, `min_subtotal: Decimal = Decimal("0")`, `expires_at: datetime | None = None`
- `CouponError`（Exception）
- `apply_coupon(subtotal: Decimal, coupon: Coupon, now: datetime) -> Decimal`

R1: kind が "percent" のとき、subtotal を value% 割り引いた金額を返す。小数第 2 位で四捨五入（ROUND_HALF_UP）する
R2: kind が "fixed" のとき、subtotal から value を引いた金額を返す。0 未満にはしない
R3: subtotal が min_subtotal 未満なら CouponError を送出する
R4: expires_at が設定されていて now がその時刻以降なら CouponError を送出する
R5: Coupon の生成時に、percent で value が 0〜100 の範囲外、fixed で value が負、kind が未知のいずれかなら ValueError を送出する
完了条件: 既存テストと追加したテストがすべて通ること
