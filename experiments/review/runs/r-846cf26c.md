# クーポン機能の追加（shoplib/pricing.py）

## 概要
`shoplib/pricing.py` にクーポン機能（`Coupon` / `CouponError` / `apply_coupon`）を追加しました。
既存の `apply_percentage_discount` は変更していません。

## 変更内容

### `shoplib/pricing.py`
- **`Coupon`**（dataclass）: `code`, `kind`（`"percent"` / `"fixed"`）, `value`, `min_subtotal`（デフォルト `Decimal("0")`）, `expires_at`（デフォルト `None`）
  - `__post_init__` で生成時に検証し、次の場合は `ValueError` を送出します（R5）
    - `kind` が `"percent"` / `"fixed"` 以外（大文字小文字は区別します。`"PERCENT"` も不可）
    - `percent` で `value` が 0〜100 の範囲外（0 と 100 は可）
    - `fixed` で `value` が負（0 は可）
- **`CouponError`**（`Exception` のサブクラス）: クーポンが適用できないときの例外。生成時の不正値（`ValueError`）とは区別できるよう、`ValueError` のサブクラスにはしていません
- **`apply_coupon(subtotal, coupon, now)`**
  - R4: `expires_at` が設定されていて `now >= expires_at` なら `CouponError`（期限ちょうども失効扱い）
  - R3: `subtotal < min_subtotal` なら `CouponError`（`min_subtotal` ちょうどは適用可）
  - R1: `percent` → `subtotal * (100 - value) / 100` を `Decimal("0.01")` に `ROUND_HALF_UP` で丸めて返します（小数の割引率 `12.5` なども可）
  - R2: `fixed` → `max(subtotal - value, 0)` を返します

### `tests/test_coupon.py`（新規）
R1〜R5 ごとに、境界値を含めたテストを追加しました（30 件）。
- R1: 基本計算 / HALF_UP 固有の丸め（`0.25` の 50% → `0.13`。HALF_EVEN なら `0.12` になるため区別できます）/ 小数の割引率 / 0% と 100%
- R2: 基本計算 / 割引額 ≥ 小計で 0 になること
- R3: 未満ならエラー / ちょうどなら適用可
- R4: 期限切れ / 期限ちょうど（エラー）/ 期限前 / 期限なし
- R5: percent の範囲外・範囲内（境界含む）/ fixed の負値・0 / 未知の kind

## 設計上の判断・注意点
- **チェックの順序**: 失効チェック（R4）を最低金額チェック（R3）より先に行います。両方に該当する場合は「期限切れ」のエラーになります。
- **fixed の結果は丸めていません**: 仕様に丸めの指定がないため、`subtotal - value` をそのまま返します（例: `Decimal("1000") - Decimal("300")` → `Decimal("700")`）。percent の結果は常に小数 2 桁（`900.00` など）になるため、両者で表記の桁数が異なります（`Decimal` の比較では同じ値として扱われます）。
- **datetime のタイムゾーン**: `now` と `expires_at` で naive / aware が混在すると、Python 標準の比較と同じく `TypeError` になります。呼び出し側でどちらかに揃える前提です。
- **型の検証はしていません**: `value` などに `Decimal` 以外が渡された場合の変換や検証は行っていません。
- `OrderService` などの既存処理にはまだ組み込んでいません（今回のスコープ外）。

 def apply_percentage_discount(amount: Decimal, percent: int) -> Decimal:
     if not 0 <= percent <= 100:
         raise ValueError("percent must be between 0 and 100")
     discounted = amount * (Decimal(100 - percent) / Decimal(100))
     return discounted.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)

+class CouponError(Exception):
+    """クーポンが適用できない（期限切れ・最低購入金額未満など）ときに送出される。"""

+@dataclass
+class Coupon:
+    code: str
+    kind: str
+    value: Decimal

+    expires_at: datetime | None = None
+
+    def __post_init__(self) -> None:
+        if self.kind not in _COUPON_KINDS:
+            raise ValueError(f"unknown coupon kind: {self.kind!r}")
+        if self.kind == COUPON_KIND_PERCENT and not _ZERO <= self.value <= _HUNDRED:
+            raise ValueError("percent coupon value must be between 0 and 100")
+        if self.kind == COUPON_KIND_FIXED and self.value < _ZERO:
+            raise ValueError("fixed coupon value must not be negative")
+
+
+def apply_coupon(subtotal: Decimal, coupon: Coupon, now: datetime) -> Decimal:
+    if coupon.expires_at is not None and now >= coupon.expires_at:
+        raise CouponError(f"coupon {coupon.code} has expired")
+    if subtotal < coupon.min_subtotal:
+        raise CouponError(f"subtotal is below the minimum ({coupon.min_subtotal}) for coupon {coupon.code}")
