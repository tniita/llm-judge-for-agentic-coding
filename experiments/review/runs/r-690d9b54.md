## PR 説明

# format_money を通貨対応（JPY / USD）にする

## 概要
`shoplib/formatting.py` の `format_money` を拡張し、通貨ごとの小数桁・3 桁区切り・四捨五入で表示できるようにしました。

シグネチャ: `format_money(amount: Decimal | int, currency: str = "JPY") -> str`

## 変更内容
### `shoplib/formatting.py`
- 通貨テーブル `_CURRENCIES`（コード -> 記号, 小数桁数）を追加
  - `JPY`: `¥`, 0 桁 / `USD`: `$`, 2 桁
- 処理の流れ
  1. **型チェック（R5）**: `Decimal` / `int` 以外は `TypeError`。`float` は誤差を避けるため受け付けない
  2. **通貨チェック（R4）**: テーブルにない通貨コードは `ValueError`
  3. **丸め（R1/R2）**: `Decimal.quantize(..., rounding=ROUND_HALF_UP)` で通貨の小数桁に丸める
  4. **整形（R1/R2/R3）**: 絶対値を `,` 区切りで整形し、負なら記号の前に `-` を付ける（`-¥1,234`、`-$0.50`）

| 入力 | 出力 |
|---|---|
| `format_money(Decimal("1234.5"))` | `¥1,235` |
| `format_money(Decimal("1234.5"), "USD")` | `$1,234.50` |
| `format_money(Decimal("-0.5"), "USD")` | `-$0.50` |
| `format_money(1234)` | `¥1,234` |
| `format_money(1.5)` | `TypeError` |
| `format_money(Decimal("1"), "EUR")` | `ValueError` |

### 仕様に明記がなく、実装時に決めた点（レビューで確認をお願いします）
- **`bool` は `TypeError`**: `bool` は `int` のサブクラスですが、`format_money(True)` → `¥1` は明らかに誤用なので拒否しています。
- **`str` / `None` などそのほかの型も `TypeError`**。
- **`Decimal("NaN")` / `Infinity` は `ValueError`**: 金額として表示できないため。
- **負数が丸めて 0 になる場合はマイナスを付けない**: `Decimal("-0.4")` は `-¥0` ではなく `¥0` になります。
- **負数の四捨五入は絶対値基準**（`ROUND_HALF_UP` の仕様どおり）: `Decimal("-1234.5")` は `-¥1,235` になります。
- **通貨コードは大文字・小文字を区別**: `"jpy"` は未対応扱いで `ValueError` になります。
- **大きな金額**: Decimal の既定精度（28 桁）を超える金額でも `quantize` が `InvalidOperation` にならないよう、関数内だけで `localcontext` の精度を引き上げています。呼び出し側のコンテキストには影響しません。

### 互換性について
- 既定の通貨は JPY なので、引数 1 つの呼び出しはそのまま使えますが、**表示は変わります**（以前の `f"¥{amount}"` では `¥1234.5`、今回から `¥1,235`）。
- リポジトリ内に `format_money` の呼び出し元はありません（grep で確認）。

+def format_money(amount: Decimal | int, currency: str = "JPY") -> str:
+    """金額を通貨に応じた表示用文字列に整形する。
+
+    - 端数は ROUND_HALF_UP（四捨五入）で通貨の小数桁数に丸める
+    - 整数部は 3 桁区切り
+    - 負の金額は記号の前にマイナスを付ける（例: "-¥1,234"）
+
+    Raises:
+        TypeError: amount が Decimal / int 以外（float や bool を含む）の場合
+        ValueError: 未対応の通貨コード、または amount が NaN / Infinity の場合
+    """
+    # bool は int のサブクラスだが金額としては不正なので明示的に除外する
+    if isinstance(amount, bool) or not isinstance(amount, (Decimal, int)):
+        raise TypeError(f"amount must be Decimal or int, not {type(amount).__name__}")
+    if currency not in _CURRENCIES:
+        raise ValueError(f"unsupported currency: {currency!r}")
+
+    value = Decimal(amount)
+    if not value.is_finite():
+        raise ValueError(f"amount must be finite: {amount!r}")
+
+    symbol, places = _CURRENCIES[currency]
+    with localcontext() as ctx:
+        # 桁数の大きい金額でも quantize が InvalidOperation にならないよう精度を確保する
+        ctx.prec = max(ctx.prec, value.adjusted() + places + 2)
+        rounded = value.quantize(Decimal(1).scaleb(-places), rounding=ROUND_HALF_UP)
+
+    # 丸め後に 0 になった負数（例: -0.4 円）は "-¥0" ではなく "¥0" とする
+    sign = "-" if rounded < 0 else ""
+    return f"{sign}{symbol}{rounded.copy_abs():,.{places}f}"
