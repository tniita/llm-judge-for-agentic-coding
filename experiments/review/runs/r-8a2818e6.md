R3: subtotal が min_subtotal 未満なら CouponError を送出する
R4: expires_at が設定されていて now がその時刻以降なら CouponError を送出する
R5: Coupon の生成時に、percent で value が 0〜100 の範囲外、fixed で value が負、kind が未知のいずれかなら ValueError を送出する
完了条件: 既存テストと追加したテストがすべて通ること

# クーポン機能の追加

## 変更内容
`shoplib/pricing.py` に以下を追加。
- `Coupon` (dataclass): 生成時に検証し、percent で 0〜100 の範囲外 / fixed で負 / 未知の kind / 非有限値(NaN 等)は `ValueError`
- `CouponError`
- `apply_coupon(subtotal, coupon, now)`
  - percent: `subtotal * (100 - value) / 100` を小数第 2 位で ROUND_HALF_UP
  - fixed: `subtotal - value`（0 未満にはしない）
  - `subtotal < min_subtotal` または `now >= expires_at` で `CouponError`

## 補足
- fixed の結果は量子化せず、入力の精度のまま返す。
- `now` と `expires_at` の naive/aware が混在すると `TypeError`（呼び出し側で揃える前提）。
