# r-b07113c9

## タスク

shoplib/pricing.py にクーポン機能を追加する。

- `Coupon`（dataclass）: `code: str`, `kind: str`（"percent" または "fixed"）, `value: Decimal`, `min_subtotal: Decimal = Decimal("0")`, `expires_at: datetime | None = None`
- `CouponError`（Exception）
- `apply_coupon(subtotal: Decimal, coupon: Coupon, now: datetime) -> Decimal`

R1: kind が "percent" のとき、subtotal を value% 割り引いた金額を返す。小数第 2 位で四捨五入（ROUND_HALF_UP）する
R2: kind が "fixed" のとき、subtotal から value を引いた金額を返す。0 未満にはしない
R3: subtotal が min_subtotal 未満なら CouponError を送出する
R4: expires_at が設定されていて now がその時刻以降なら CouponError を送出する
R5: Coupon の生成時に、percent で value が 0〜100 の範囲外、fixed で value が負、kind が未知のいずれかなら ValueError を送出する
完了条件: 既存テストと追加したテストがすべて通ること

## PR 説明

# クーポン機能の追加（shoplib/pricing.py）

## 変更内容
- `shoplib/pricing.py`
  - `Coupon`（`frozen=True` の dataclass）を追加。`__post_init__` で検証し、次の場合に `ValueError` を送出（R5）
    - `percent` で `value` が 0〜100（両端を含む）の範囲外
    - `fixed` で `value` が負
    - `kind` が未知
  - `apply_coupon(subtotal, coupon, now) -> Decimal` を追加
    - `expires_at` が設定されていて `now >= expires_at` なら `CouponError`（R4）
    - `subtotal < min_subtotal` なら `CouponError`（R3。同額なら適用可）
    - `percent`: `subtotal × (100 − value) / 100` を小数第 2 位で `ROUND_HALF_UP`（R1）
    - `fixed`: `max(subtotal − value, 0)`（R2）
  - 既存の `apply_percentage_discount` の動作は変更なし（丸め単位を定数 `CENT` にまとめただけ）
- `shoplib/errors.py`（新規）: `CouponError` を定義。コーディング規約の「ドメイン例外は `errors.py` に定義する」に従った。`from shoplib.pricing import CouponError` でも import できるように再 export している

## 設計上の判断
- ADR-001 に従い、時刻は `now` 引数で受け取る（`datetime.now()` は呼ばない）
- 金額はすべて `Decimal` で扱う
- `Coupon` は frozen にした。生成後に値を変更して検証をすり抜けられないようにするため
- 有効期限と最低購入金額の両方を満たさない場合は、有効期限のエラーを先に送出する
- `shoplib/__init__.py` の公開 API は変更していない
