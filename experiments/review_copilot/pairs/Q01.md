# Q01: どちらをマージすべきか

## タスク

商品カテゴリごとの消費税計算を追加する。

- 新規モジュール `shoplib/tax.py`
- `TaxBreakdown`（dataclass）: `subtotal: Decimal`, `tax: Decimal`, `total: Decimal`
- `calculate_tax(items: list[CartItem], rates: dict[str, Decimal], default_rate: Decimal = Decimal("0.10")) -> TaxBreakdown`

R1: 税額は明細（CartItem）ごとに「明細の小計 × 税率」を計算し、1 円未満を切り捨て（ROUND_DOWN）てから合計する
R2: 税率は商品の category をキーに rates から引く。無ければ default_rate を使う
R3: total は subtotal + tax
R4: rates の値または default_rate が 0 未満または 1 より大きければ ValueError を送出する
R5: items が空なら subtotal・tax・total はすべて 0
完了条件: 既存テストと追加したテストがすべて通ること

+from dataclasses import dataclass
+from decimal import ROUND_DOWN, Decimal
+
+from shoplib.models import CartItem

+@dataclass
+class TaxBreakdown:
+    subtotal: Decimal
+    tax: Decimal
+    total: Decimal
+
+
+def calculate_tax(
+    items: list[CartItem],
+    rates: dict[str, Decimal],
+    default_rate: Decimal = Decimal("0.10"),
+) -> TaxBreakdown:
+    if not Decimal("0") <= default_rate <= Decimal("1"):
+        raise ValueError("default_rate must be between 0 and 1")
+    if any(not Decimal("0") <= rate <= Decimal("1") for rate in rates.values()):
+        raise ValueError("rates must be between 0 and 1")
+
+    subtotal = sum((item.subtotal for item in items), Decimal("0"))
+    tax = sum(
+        (
+            (item.subtotal * rates.get(item.product.category, default_rate)).quantize(
+                Decimal("1"), rounding=ROUND_DOWN
+            )
+            for item in items
+        ),
+        Decimal("0"),
+    )
+    return TaxBreakdown(subtotal=subtotal, tax=tax, total=subtotal + tax)

+from dataclasses import dataclass
+from decimal import ROUND_DOWN, Decimal
+
+from shoplib.models import CartItem
+
+_MIN_RATE = Decimal("0")
+_MAX_RATE = Decimal("1")
+_YEN = Decimal("1")
+
+
+@dataclass(frozen=True)
+class TaxBreakdown:
+    subtotal: Decimal
+    tax: Decimal
+    total: Decimal
+
+
+def _validate_rate(rate: Decimal, name: str) -> None:
+    if not _MIN_RATE <= rate <= _MAX_RATE:
+        raise ValueError(f"{name} must be between 0 and 1: {rate}")
+
+
+def calculate_tax(
+    items: list[CartItem],
+    rates: dict[str, Decimal],
+    default_rate: Decimal = Decimal("0.10"),
+) -> TaxBreakdown:
+    _validate_rate(default_rate, "default_rate")
+    for category, rate in rates.items():
+        _validate_rate(rate, f"rate for category {category!r}")
+
+    subtotal = Decimal("0")
+    tax = Decimal("0")
+    for item in items:
+        rate = rates.get(item.product.category, default_rate)
+        line_subtotal = item.subtotal
+        subtotal += line_subtotal
+        tax += (line_subtotal * rate).quantize(_YEN, rounding=ROUND_DOWN)
+    return TaxBreakdown(subtotal=subtotal, tax=tax, total=subtotal + tax)
