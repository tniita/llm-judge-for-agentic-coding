# Q05: どちらをマージすべきか

## タスク

shoplib/formatting.py の `format_money` を、通貨に応じた表示ができるように拡張する。

- シグネチャ: `format_money(amount: Decimal | int, currency: str = "JPY") -> str`

R1: JPY は小数なし・3 桁区切りで表示する（例: Decimal("1234.5") → "¥1,235"）。端数は四捨五入（ROUND_HALF_UP）
R2: USD は小数 2 桁・3 桁区切りで表示する（例: Decimal("1234.5") → "$1,234.50"）。端数は四捨五入（ROUND_HALF_UP）
R3: 負の金額は記号の前にマイナスを付ける（例: "-¥1,234"、"-$0.50"）
R4: 対応していない通貨コードなら ValueError を送出する
R5: float が渡されたら TypeError を送出する（誤差を避けるため）。int は受け付ける
完了条件: 既存テストと追加したテストがすべて通ること
