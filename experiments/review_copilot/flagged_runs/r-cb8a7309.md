# r-cb8a7309

## タスク

shoplib/pricing.py にクーポン機能を追加する。

- `Coupon`（dataclass）: `code: str`, `kind: str`（"percent" または "fixed"）, `value: Decimal`, `min_subtotal: Decimal = Decimal("0")`, `expires_at: datetime | None = None`
- `CouponError`（Exception）
- `apply_coupon(subtotal: Decimal, coupon: Coupon, now: datetime) -> Decimal`

R1: kind が "percent" のとき、subtotal を value% 割り引いた金額を返す。小数第 2 位で四捨五入（ROUND_HALF_UP）する
R2: kind が "fixed" のとき、subtotal から value を引いた金額を返す。0 未満にはしない
R3: subtotal が min_subtotal 未満なら CouponError を送出する
R4: expires_at が設定されていて now がその時刻以降なら CouponError を送出する
R5: Coupon の生成時に、percent で value が 0〜100 の範囲外、fixed で value が負、kind が未知のいずれかなら ValueError を送出する
完了条件: 既存テストと追加したテストがすべて通ること

## PR 説明

# PR Description

クーポン機能を `shoplib/pricing.py` に追加しました。`Coupon` dataclass はクーポン種別と割引額を生成時に検証し、`apply_coupon` は最低購入額と有効期限を確認したうえで、パーセント割引（小数第2位で `ROUND_HALF_UP`）または 0 を下限とする固定額割引を適用します。無効条件には `CouponError` を送出します。既存の `apply_percentage_discount` は変更していません。

`tests/test_pricing.py` に丸め、固定額の下限、最低購入額、有効期限（期限と同時刻を含む）、生成時の不正値を検証するテストを追加しました。

+class CouponError(Exception):
+    """Raised when a coupon cannot be applied to a subtotal."""

+@dataclass
+class Coupon:
+    code: str
+    kind: str
+    value: Decimal

+    expires_at: datetime | None = None
+
+    def __post_init__(self) -> None:
+        if self.kind == "percent":
+            if not Decimal("0") <= self.value <= Decimal("100"):
+                raise ValueError("percent coupon value must be between 0 and 100")
+        elif self.kind == "fixed":
+            if self.value < Decimal("0"):
+                raise ValueError("fixed coupon value must not be negative")
+        else:
+            raise ValueError(f"unknown coupon kind: {self.kind}")

+def apply_coupon(subtotal: Decimal, coupon: Coupon, now: datetime) -> Decimal:
+    if subtotal < coupon.min_subtotal:
+        raise CouponError("subtotal is below the coupon minimum")
+    if coupon.expires_at is not None and now >= coupon.expires_at:
+        raise CouponError("coupon has expired")
+
+    if coupon.kind == "percent":
+        discounted = subtotal * (Decimal("100") - coupon.value) / Decimal("100")
+        return discounted.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)
+    return max(Decimal("0"), subtotal - coupon.value)
