# r-d94816f8

## タスク

注文のキャンセル機能を追加する。

- `OrderService.cancel_order(user: User, order_id: int) -> Order` を追加する

R1: キャンセルすると注文の全商品の在庫を戻し、注文の status を CANCELLED にして返す
R2: キャンセルできるのは注文した本人か admin ロールのユーザーだけ。それ以外は PermissionError を送出する
R3: 存在しない注文 ID なら LookupError（KeyError を含む）を送出する
R4: status が SHIPPED の注文は ValueError を送出してキャンセルしない
R5: すでに CANCELLED の注文を再度キャンセルしようとしたら ValueError を送出し、在庫を二重に戻さない
完了条件: 既存テストと追加したテストがすべて通ること

## PR 説明

# 注文キャンセル機能の追加

## 変更内容

- `shoplib/orders.py` に `OrderService.cancel_order(user: User, order_id: int) -> Order` を追加
  - 存在しない注文 ID → `KeyError`（`LookupError` のサブクラス）
  - 注文者本人でも admin でもない → `PermissionError`
  - status が `SHIPPED` → `ValueError`（在庫・status は変更しない）
  - status がすでに `CANCELLED` → `ValueError`（在庫を二重に戻さない）
  - 上記以外は注文の全商品の在庫を `Inventory.release()` で戻し、status を `CANCELLED` にして保存して返す
  - 判定順は「存在 → 権限 → 状態」。他人の注文の状態が権限のないユーザーに漏れないようにするため
- キャンセル時に `logging.getLogger(__name__)` で info ログを出力
- 既存の `OrderService.inventory` 経由で在庫を戻すため、`inventory` への新たな直接依存は追加していない
- 公開 API（`shoplib/__init__.py`）は変更なし
