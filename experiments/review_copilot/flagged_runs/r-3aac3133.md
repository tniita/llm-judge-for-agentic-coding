# r-3aac3133

## タスク

ユーザーごとの API 呼び出しを制限するレートリミッターを追加する。

- 新規モジュール `shoplib/ratelimit.py`
- `RateLimiter(capacity: int, refill_per_sec: float, clock=time.monotonic)`
- `allow(key: str) -> bool`

R1: トークンバケット方式。キーごとに満杯（capacity 個）の状態から始まり、allow が True を返すたびにトークンを 1 消費する。トークンが 1 未満なら False を返す
R2: トークンは経過時間 × refill_per_sec だけ連続的に補充され、capacity を超えない
R3: キーごとに独立して管理する
R4: capacity が 1 未満、または refill_per_sec が 0 以下なら ValueError を送出する
R5: 複数スレッドから同時に呼ばれても、許可回数が capacity を超えない（スレッドセーフ）
R6: 時刻は clock から取得し、テストで差し替えられるようにする
完了条件: 既存テストと追加したテストがすべて通ること

## PR 説明

# PR 説明

ユーザーごとの API 呼び出しを制限するトークンバケット方式の `RateLimiter` を追加しました。キーごとに独立したバケットを管理し、トークンを経過時間に応じて連続補充します。共有状態の更新はロックで保護し、時計は `clock` 引数で差し替え可能です。不正な容量または補充率には `ValueError` を送出します。

- `pytest -q`
- `ruff check .`

+import threading
+import time
+from collections.abc import Callable
+
+
+class RateLimiter:
+    def __init__(
+        self,
+        capacity: int,
+        refill_per_sec: float,
+        clock: Callable[[], float] = time.monotonic,
+    ) -> None:
+        if capacity < 1:
+            raise ValueError("capacity must be at least 1")
+        if refill_per_sec <= 0:
+            raise ValueError("refill_per_sec must be greater than 0")
+
+        self._capacity = capacity
+        self._refill_per_sec = refill_per_sec
+        self._clock = clock
+        self._buckets: dict[str, tuple[float, float]] = {}
+        self._lock = threading.Lock()
+
+    def allow(self, key: str) -> bool:
+        with self._lock:
+            now = self._clock()
+            tokens, last_refill = self._buckets.get(key, (float(self._capacity), now))
+            elapsed = max(0.0, now - last_refill)
+            tokens = min(self._capacity, tokens + elapsed * self._refill_per_sec)
+
+            if tokens < 1:
+                self._buckets[key] = (tokens, now)
+                return False
+
+            self._buckets[key] = (tokens - 1, now)
+            return True
