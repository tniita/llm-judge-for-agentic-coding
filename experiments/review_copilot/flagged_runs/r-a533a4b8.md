## 仕様

| 要件 | 実装 |
|---|---|
| R1 | 1 行目をヘッダーとして読む。`sku`, `name`, `price` は必須、`category` は任意（無い場合や空の場合は `"general"`）。列の順番は問わない。`price` は `Decimal` に変換する |
| R2 | 必須列がヘッダーに無い場合や、CSV が空の場合は `ValueError` を送出する |
| R3 | `price` が数値でない（空、`NaN`、`Infinity` を含む）または負の行は、`(行番号, 理由)` を errors に記録してスキップする。`0` は有効な値として扱う |
| R4 | 採用済みの sku と重複した行は、errors に記録してスキップする（最初の行を採用する） |
| R5 | 空行や空白だけの行は無視する。ヘッダーと各値の前後の空白は取り除く。sku または name が空の行は errors に記録してスキップする |

- 行番号は `csv.reader.line_num` を使い、ヘッダーを 1 行目として数える。空行も行数に含める
- 前の行がエラーでスキップされた場合、同じ sku を持つ後の正しい行は重複として扱わず、採用する
- 規約に従い、金額は `Decimal` で扱い、標準ライブラリの `csv` だけを使う。ファイル I/O は呼び出し側に任せる（ADR-001）。依存先は `models` だけ
- 公開 API を変えないため、`shoplib/__init__.py` は変更していない

## ADR-001: 外部 I/O をドメインロジックから分離する

- 決定: ドメインロジックはファイル・ネットワーク・時刻に直接アクセスしない。時刻は引数（`now: datetime`）で受け取る
- 理由: テストを決定的にするため

+import csv
+import io
+import logging
+from dataclasses import dataclass, field
+from decimal import Decimal, InvalidOperation
+
+from shoplib.models import Product
+
+logger = logging.getLogger(__name__)
+
+REQUIRED_COLUMNS = ("sku", "name", "price")
+DEFAULT_CATEGORY = "general"
+
+
+@dataclass
+class ImportResult:
+    products: list[Product] = field(default_factory=list)
+    errors: list[tuple[int, str]] = field(default_factory=list)
+
+
+def _parse_price(raw: str) -> Decimal:
+    try:
+        price = Decimal(raw)
+    except InvalidOperation:
+        raise ValueError(f"price is not a number: {raw!r}") from None
+    if not price.is_finite():
+        raise ValueError(f"price is not a number: {raw!r}")
+    if price < 0:
+        raise ValueError(f"price must not be negative: {raw!r}")
+    return price
+
+
+def import_products(csv_text: str) -> ImportResult:
+    """Parse CSV text (with a header row) into products.
+
+    Line numbers in ``errors`` count the header as line 1.
+    Raises ValueError if a required column is missing from the header.
+    """
+    reader = csv.reader(io.StringIO(csv_text))
+    header = next(reader, None)
+    columns = [c.strip() for c in header] if header else []
+    missing = [c for c in REQUIRED_COLUMNS if c not in columns]
+    if missing:
+        raise ValueError(f"missing required columns: {', '.join(missing)}")
+    index = {name: columns.index(name) for name in (*REQUIRED_COLUMNS, "category") if name in columns}
+
+    result = ImportResult()
+    seen_skus: dict[str, int] = {}
+    for row in reader:
+        line_no = reader.line_num
+        values = [v.strip() for v in row]
+        if not any(values):
+            continue
+
+        def get(name: str, values: list[str] = values) -> str:
+            i = index.get(name)
+            return values[i] if i is not None and i < len(values) else ""
+
+        sku, name = get("sku"), get("name")
+        if not sku:
+            result.errors.append((line_no, "sku is empty"))
+            continue
+        if not name:
+            result.errors.append((line_no, "name is empty"))
+            continue
+        try:
+            price = _parse_price(get("price"))
+        except ValueError as e:
+            result.errors.append((line_no, str(e)))
+            continue
+        if sku in seen_skus:
+            result.errors.append((line_no, f"duplicate sku {sku!r} (first seen on line {seen_skus[sku]})"))
+            continue
+
+        seen_skus[sku] = line_no
+        result.products.append(Product(sku, name, price, get("category") or DEFAULT_CATEGORY))
+
+    if result.errors:
+        logger.info("imported %d products, skipped %d rows", len(result.products), len(result.errors))
+    return result
