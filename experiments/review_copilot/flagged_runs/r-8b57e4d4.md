shoplib/cart.py の Cart が不正な数量を受け付けてしまう不具合を修正する。

R1: `add` に 0 以下の数量を渡したら ValueError を送出する
R2: `remove` に 0 以下の数量を渡したら ValueError を送出する
R3: `remove` でカート内の数量より多く取り除こうとしたら ValueError を送出し、カートの中身は変えない
R4: `remove` で数量がちょうど 0 になった商品はカートから消える（現在の挙動を維持）
R5: `add` / `remove` の数量が int 以外（float や bool など）なら TypeError を送出する
R6: カートに無い SKU を `remove` したら KeyError を送出する（現在の挙動を維持）
完了条件: 既存テストと追加したテストがすべて通ること

## PR 説明

# Cart: 不正な数量を拒否する

## 概要
`shoplib/cart.py` の `Cart.add` / `Cart.remove` が 0 以下の数量、int 以外の数量、カート内の数量を超える削除を受け付けていた不具合を修正しました。

## 変更内容
- `shoplib/cart.py`
  - 数量チェック用のヘルパー `_validate_quantity` を追加しました。
    - int 以外（float、str、None など）は `TypeError` にします。`bool` は `int` のサブクラスなので、明示的に除外しています（R5）。
    - 0 以下は `ValueError` にします（R1, R2）。
  - `add`: 先頭で数量をチェックします。不正な場合はカートを変更しません。
  - `remove`: 数量をチェックしてから SKU を参照します。カートに無い SKU はこれまでどおり `KeyError` です（R6）。カート内の数量を超える場合は、数量を減らす前に `ValueError` を送出するため、カートの中身は変わりません（R3）。数量がちょうど 0 になった商品は、これまでどおりカートから消えます（R4）。
- `tests/test_cart.py`（新規）: R1〜R6 を検証するテストを追加しました。例外が起きたときにカートの中身が変わらないことも確認しています。

## 互換性
公開 API のシグネチャと戻り値は変えていません。正しい数量を渡す既存の呼び出しの挙動も同じです。
