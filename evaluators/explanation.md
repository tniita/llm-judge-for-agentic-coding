# 観点: 説明（0〜5）
PR 説明と差分内のコメントが、実際の変更内容と一致しているかを判定する。
文章の上手さ・長さ・丁寧さは評価しない。事実との一致だけを見る。
- PR 説明に書かれているのに、差分に実装されていない内容はないか
- 差分で行われている重要な変更（挙動変更、破壊的変更、設定・依存の追加）が説明から漏れていないか
- コード内コメントが実装と食い違っていないか
- 影響範囲や確認方法が書かれている場合、内容が差分と矛盾していないか

# 採点基準
- 5: 説明と差分が完全に一致し、重要な変更がすべて説明されている
- 4: 一致しているが、重要度の低い変更の説明が一部漏れている
- 3: 重要な変更の説明漏れ、または軽微な食い違いがある
- 2: 説明と差分に明確な食い違いがある
- 1: 実装していない内容を実装済みと説明しているなど、誤解を招く記述がある
- 0: PR 説明が空、または差分と無関係

# reason の書式
`[confidence: ...] 一致: ... / 食い違い・漏れ: ...（説明の該当箇所 ↔ ファイル:行） / 総評: ...`
